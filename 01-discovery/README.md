# Descubrimiento del Sistema

En la siguiente documentación se presenta la visión y los requerimientos de alto nivel para **Keygo**, una plataforma de autenticación, autorización y gestión de identidad para organizaciones multi-tenant. La motivación central permanece: superar la gestión fragmentada de identidades, accesos y credenciales en ecosistemas multi-aplicación, consolidando identidad y acceso mediante límites de tenant claros, autorización granular, trazabilidad y protocolos abiertos.

> [!IMPORTANT]
> **Reconciliación de alcance 2026-09-07:** la misión IAM anterior se mantiene y pasa a ser el límite objetivo explícito de `INIT-KEYGO-001 / CAP-IAM-001`. Las capacidades comerciales de suscripción/entitlements y payment execution que existen en la implementación actual dejan de ser target ownership de KeyGo. Consulte [Scope Reconciliation](scope-reconciliation-2026-09-07.md). El cambio de autoridad semántica no significa que la migración de código/datos/UI ya haya ocurrido.

El discovery histórico conserva valor como fuente de procedencia, pero cuando un texto previo contradiga la reconciliación de 2026-09-07, prevalece la decisión `DEC-KEYGO-SCOPE-001` y sus referencias ADÜMÜN.
